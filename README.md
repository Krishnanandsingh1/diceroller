# 🎲 Dice Roller App

This is a simple Android app that rolls a dice and shows a random number.

## 📱 Features
- 🎲 Roll a dice
- 🔢 Random number (1 to 6)
- 🎨 Simple and clean UI

## 🚀 How to Run
1. Open project in Android Studio
2. Click on Run ▶️
3. App will start on emulator or mobile

## 🛠️ Tech Used
- Kotlin
- Android Studio
